Ingest a metric

Submit a validated event. Accepted events are written to Kafka and return HTTP 202.

curl -X POST http://localhost:8001/v1/metrics \
  -H 'content-type: application/json' \
  -d '{"name":"checkout.duration","value":184.2,"source":"storefront"}'
